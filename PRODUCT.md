# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
GitHub Profile README: Markdown, HTML permitido por GitHub e imágenes del propio repositorio. Python estándar para calcular datos públicos. La plataforma impone el stack; no se crea un servidor local.

## Users
Visitantes del perfil público erickopgaming28 que quieren conocer sus proyectos y abrirlos.

## Product Purpose
El usuario pide mejorar un perfil genérico y darle vida con estética de videojuego, niveles y misiones. Mostrar herramientas reales con una presentación personal y legible.

## Constraints
Conservar privados los repositorios privados existentes. Usar únicamente datos públicos verificables para las estadísticas. No presentar XP como una medida real de competencia profesional. No inventar clientes, logros, experiencia laboral o habilidades porcentuales.

## Evidence
La cuenta pública es erickopgaming28. No existe repositorio de perfil y los campos name y bio están vacíos al iniciar. Proyectos públicos verificados: pluma-a1, clasificador-de-musica y ai-token-monitor; autoshorts-legal contiene documentos legales.

## Confirmed Visual Brief
El usuario eligió explícitamente «RPG de fantasía y árbol de habilidades». El perfil es una ficha de artífice aventurero, con niveles, XP y tres ramas de proyectos. El estilo RPG manda sobre las alternativas del selector. No se cambia la foto del usuario.
