## Diario de misiones

### La forja del Artífice · [Pluma A1](https://github.com/erickopgaming28/pluma-a1)

**Llevar el código al papel.** Un editor local en español para preparar escritura y dibujos de una línea con una Bambu Lab A1. Del diseño a los trazos, con control sobre la composición.

`Python` · `SVG` · `Trazado` &nbsp; **[Entrar a la forja →](https://github.com/erickopgaming28/pluma-a1#readme)**

### La torre del Bardo · [Clasificador de Música](https://github.com/erickopgaming28/clasificador-de-musica)

**Encontrar el orden entre canciones.** Clasifica música de Spotify por género, estilo, ánimo, ocasión y época para crear playlists; la ayuda de IA es opcional.

`JavaScript` · `Node.js` · `Spotify API` &nbsp; **[Subir a la torre →](https://github.com/erickopgaming28/clasificador-de-musica#readme)**

### El observatorio del Arcanista · [AI Token Monitor](https://github.com/erickopgaming28/ai-token-monitor)

**Entender el consumo de las herramientas de IA.** Un monitor de bandeja que registra tokens por proyecto, conserva el historial local y permite consultar estimaciones de costo.

`Python` · `PySide6` · `SQLite` &nbsp; **[Abrir el observatorio →](https://github.com/erickopgaming28/ai-token-monitor#readme)**

<summary><strong>Reglas de la experiencia y próximos niveles</strong></summary>

Cada repositorio público propio aporta **100 XP** y cada estrella recibida en esos repositorios aporta **25 XP**. Se excluyen este perfil y los forks. Cada 100 XP se sube un nivel; la aventura empieza en el nivel 1.

Es un sistema lúdico para este perfil: las ramas representan tecnologías presentes en los proyectos, y el nivel refleja esta fórmula. La captura solo utiliza datos públicos de GitHub. Se recalcula al ejecutar la acción **Actualizar ficha RPG** o al cambiar su generador; puedes consultar la [captura y fórmula](assets/progreso.json).
