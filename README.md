## Misiones

**[Pluma A1](https://github.com/erickopgaming28/pluma-a1)** · La forja del Artífice<br>
Editor local en español para preparar escritura y dibujos con una Bambu Lab A1.<br>
`Python` · `SVG` · `Trazado`

**[Clasificador de Música](https://github.com/erickopgaming28/clasificador-de-musica)** · La torre del Bardo<br>
Organiza música de Spotify por género, ánimo y ocasión, y crea playlists. IA opcional.<br>
`JavaScript` · `Node.js` · `Spotify API`

**[AI Token Monitor](https://github.com/erickopgaming28/ai-token-monitor)** · El observatorio<br>
Consulta el consumo de tokens por proyecto, con historial local y estimaciones de costo.<br>
`Python` · `PySide6` · `SQLite`
